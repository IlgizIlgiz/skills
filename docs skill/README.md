# Docs Skill for Claude Code

Скилл для организации документации проекта. Разбивает CLAUDE.md на компактное ядро с тегами + подробные файлы в `docs/`.

## Что умеет

- **Первый запуск** — анализирует CLAUDE.md, разделяет на essential (ядро) + detailed (docs/), создаёт структуру
- **Повторный запуск** — проверяет актуальность документации по коду, обновляет расхождения
- **Верификация** — проверяет файлы, зависимости, команды, CI/CD на соответствие документации
- **Безопасность** — предупреждает о секретах в документации

## Установка

Скопировать команду глобально (доступна во всех проектах):

```bash
cp "docs skill/commands/docs.md" ~/.claude/commands/docs.md
```

## Использование

```
/docs              # Полный цикл: анализ + реорганизация + верификация
/docs обнови api   # Обновить только секцию API
```

## Формат CLAUDE.md после организации

```markdown
# Название проекта

<!-- DOCS: При изменении документации используй /docs — не редактируй CLAUDE.md вручную -->

<!-- ESSENTIAL:START — Ядро проекта. Обновлять через /docs, не трогать вручную -->

[Компактная информация для каждой сессии]

<!-- ESSENTIAL:END -->

## Подробная документация

- [Web App](docs/web.md) — описание
- [API](docs/api.md) — описание
```

## Принцип работы

1. **ESSENTIAL блок** (в CLAUDE.md) — минимум информации, нужный при каждой сессии: описание проекта, стек, сервер, деплой, команды разработки, troubleshooting
2. **docs/ файлы** — детальная документация по компонентам, читается только при работе с конкретным компонентом
3. **Теги** (`ESSENTIAL:START/END`) — скилл знает что трогать, а что нет, при повторных запусках
4. **Верификация** — каждый запуск проверяет актуальность по реальному состоянию кода

## Что создаётся в проекте

```
CLAUDE.md                # Компактное ядро + ссылки
docs/
├── web.md               # Веб-приложение
├── api.md               # API
├── bot.md               # Бот
├── deploy.md            # Деплой
└── ...                  # Другие компоненты
```
